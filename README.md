# NOVA Calculator 🚀

**More than just a calculator.**

NOVA Calculator is a modern scientific calculator built with Python and Streamlit. It combines a clean, interactive interface with powerful mathematical capabilities to make calculations simple and accessible.

## ✨ Features

- **Basic Operations:** Addition, subtraction, multiplication, and division.
- **Scientific Functions:** Sine, cosine, tangent, square root, logarithms, and exponential functions.
- **Angle Modes:** Switch between Degrees (DEG) and Radians (RAD).
- **Calculation History:** Keep track of previous calculations.
- **Modern Interface:** A custom-designed interface with a dark theme.
- **Safe Expression Evaluation:** Uses a restricted expression evaluator to handle mathematical input safely.

## 🛠️ Built With

- Python
- Streamlit
- SymPy

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mora12p/NOVA-Calculator.git
cd NOVA-Calculator
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.
