# Scientific Calculator

A simple scientific calculator built with Python and Streamlit. It supports basic arithmetic operations, trigonometric functions (with DEG/RAD switching), logarithms, powers, and keeps a history of previous calculations during the session.

## Features
- Basic math operations (+, -, *, /, %, powers)
- Scientific functions (sin, cos, tan, sqrt, log, ln, exp, abs)
- Switch between Degrees (DEG) and Radians (RAD)
- Calculation history panel with an option to reload past expressions

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/mora12p/NOVA-Calculator.git
   cd your-repo-name
   ```

2. Install Streamlit:
   ```bash
   pip install -r requirements.txt
   ```

3. Start the app:
   ```bash
   streamlit run app.py
   ```
